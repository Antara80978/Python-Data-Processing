# Task 9 - Python Data Processing

## AI & ML Internship - Day 9

### Objective

The objective of this task is to process a collection of student records using Python and generate a summary containing useful statistics.

### Description

In this task, I created a small dataset containing student details such as student ID, name, department, and marks. I used a list of dictionaries to store the records and wrote functions to calculate summary statistics and filter students based on their marks.

### Tools Used

* Python
* Jupyter Notebook

### Concepts Used

* Lists and dictionaries
* For loops
* Functions
* List comprehension
* Conditional statements
* Built-in functions such as `sum()`, `min()`, and `max()`
* Basic data processing

### Operations Performed

1. Created a collection of student records.
2. Displayed student information.
3. Calculated the total number of students and total marks.
4. Calculated average, highest, and lowest marks.
5. Counted passed and failed students using 40 as the passing mark.
6. Calculated the pass percentage.
7. Identified the student with the highest marks.
8. Filtered students who scored 80 or above.

### How to Run

1. Clone or download this repository.
2. Open the notebook in Jupyter Notebook or Google Colab.
3. Run the cells from top to bottom.
4. Observe the summary statistics and filtered student records.

### Result

The program successfully processes the student records and displays summary statistics. It also filters students based on a marks condition.
